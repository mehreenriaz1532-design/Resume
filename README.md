# Mehreen Riaz — Personal Resume Page

A clean, modern, and ATS-friendly personal resume web page built using **HTML5** and **CSS3**. Optimized for printable single-page PDF generation, responsive viewing, and fast loading.

## 🌟 Key Features

- **ATS-Friendly Structure:** Formatted with standard typography (`Times New Roman`) and clear semantic sections for seamless Applicant Tracking System parsing.
- **Print & PDF Ready:** Includes custom `@media print` CSS rules and a dedicated one-click **"Print / Save as PDF"** action bar.
- **Responsive Contact Header:** Styled header displaying Email, LinkedIn, and GitHub links cleanly without wrapping breaks.
- **Comprehensive Sections Included:**
  - Education (Tabular Format)
  - Work Experience (Frontend Internships)
  - Leadership & Volunteer Experience
  - Technical Projects
  - Honors & Achievements
  - Certifications (Google Professional Certificates)
  - Technical Skills & Tools

## 🛠️ Built With

- **HTML5** — Semantic layout and structural elements.
- **CSS3** — Flexbox layouts, responsive design, and print utility styles.
